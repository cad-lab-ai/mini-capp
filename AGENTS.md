# mini CAPP

Начинать с README.md. Самостоятельный MCP-сервис; основная ветка main.
Паспорт — реальный каталог, не единый JSON/Markdown и не скрытая БД.
Стабильные ID не зависят от пути. Старые ревизии неизменяемы.
Изменения только пакетами с expected_revision и откатом при ошибке.
Не выдавать структурную проверку за инженерную или оформление по ЕСТД.
Новые возможности проверять через доменные тесты и MCP stdio roundtrip.
Запуск: uv sync --frozen; uv run --frozen pytest -q.
Рабочие данные/секреты не коммитить. Общие документы cad-lab — в docs/ контейнера.
Позиционирование: демонстрационная САПР ТП для предприятий; следующий шаг — персональное
внедрение и интеграция с системами конкретного предприятия. Не обещать готовую интеграцию.
После изменения Python-ядра: uv run --frozen python tools/package_plugin.py;
plugin/runtime.json и plugin/tools.json должны соответствовать исходникам.
GitLab — источник, GitHub — CI-зеркало main и тегов; прямые изменения в GitHub не вести.
В публикуемых файлах не размещать ссылки на внутренний GitLab или другие внутренние
сервисы. В README, карточке и публичной документации использовать только публичные адреса.
